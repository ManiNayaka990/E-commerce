# 🛒 E-Commerce Frontend

A React-based frontend for a full-stack **E-Commerce application**.

This project provides the user interface for interacting with the e-commerce platform, including authentication, navigation, shopping-related features, and communication with the backend API.

## 🚀 Tech Stack

* **React.js**
* **Vite**
* **JavaScript**
* **React Router**
* **HTML5**
* **CSS3**
* **REST API**

## ✨ Features

* 🔐 User authentication
* 👤 Customer and seller interfaces
* 🛍️ E-commerce product interface
* 🛒 Shopping cart functionality
* ❤️ Wishlist functionality
* 📦 Order-related functionality
* 🚚 Delivery-related interface
* 🧭 Client-side routing
* 🔗 Backend API integration
* 📱 Component-based React architecture

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm

### 1. Clone the repository

```bash
git clone https://github.com/ManiNayaka990/E-commerce.git
```

### 2. Navigate to the frontend

```bash
cd E-commerce/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will provide a local development URL in the terminal, usually:

```text
http://localhost:5173
```

## 🔗 Backend

This frontend is designed to work with the backend included in the same repository.

Backend:

```text
E-commerce/backend
```

Make sure the backend server is running when using features that require API communication.
